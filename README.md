# Xinying Guo

Personal research homepage: https://gxyes.github.io/

Static HTML, CSS and JavaScript. No build step is required.

- `content.js`: publications, projects, news, experience and awards.
- `styles.css`: layout and visual theme.
- `app.js`: navigation, search, filters and media dialogs.
- `stars.js`: GitHub star counts.
- `assets/`: profile photo, institution logos and research media from the corresponding project teams.

For GitHub Pages, publish the `main` branch from the repository root.
